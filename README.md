# Spring Core Bean Wiring

## Description

A beginner-friendly Java project demonstrating Bean Wiring and Dependency Injection in Spring Core using XML configuration.

## Concepts Covered

* Spring IoC Container
* Spring Beans and Bean Configuration
* Bean Wiring
* Dependency Injection (DI)
* Constructor Injection
* Setter Injection
* Autowiring by Name
* Autowiring by Type

## Technologies Used

* Java
* Spring Core
* Maven
* XML Configuration

## Learning Objective

To understand how Spring creates objects and connects dependent objects automatically or through explicit XML configuration.
